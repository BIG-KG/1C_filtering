## Ввод карты

Введите карту в стандартный ввод:

```text
[nodes_count] [passages_count] [clear_cost] [start_node]
[prize_0] [prize_1] ... [prize_N_minus_1]
from to probability_open
... по одной строке на каждый проход
```

Первая строка задаёт число вершин, число проходов, стоимость расчистки и
номер стартовой вершины. Далее идут призы вершин и описания проходов.

- Вершины нумеруются с нуля. Проходы нумеруются с нуля в порядке ввода.
- Призы должны быть неотрицательными, а `clear_cost` — положительной.
- `probability_open` — вероятность того, что проход открыт: от `0` до `1`.
- Проходы неориентированные. `start_node` должен быть номером существующей вершины.

Пример: две комнаты, один проход, старт в комнате `1`:

```text
2 1 4 1
10 5
0 1 1
```
